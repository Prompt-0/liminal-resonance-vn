# Ticket 000: Initial Scope & Genre Selection
**Label**: `wayfinder:task`
**Status**: Closed

## Question
What are the fundamental boundaries, genre conventions, and engine format for the visual novel vertical slice?

## Resolution
- Genre: Psychological Horror (Atmospheric uncanny dread, cognitive drift, meta-UI distortions).
- Target: 15–20 minute playable vertical slice (Prologue / Chapter 1) with 3 distinct endings.
- Engine: Web-native React 19 + TypeScript + Vite on port 3000 with Web Audio API synthesis.
- Audio/Visual: Layered 2D character sprites, CRT/scanline/glitch shaders, procedural binaural drone audio synthesis.
